Rapport hebdomadaire des projets populaires GitHub — la semaine écoulée

Fenêtre temporelle : du 2026-11-01 au 2026-11-07 (GitHub Trending since=weekly) Heure de vérification : 2026-11-07 08:00 CST (Asia/Shanghai) Note méthodologique : le classement suit l’ordre d’affichage du classement hebdomadaire officiel GitHub Trending ; le nombre d’étoiles gagnées cette semaine est tiré d’un instantané d’un site agrégateur tiers (2026-11-07 03:38, heure de Pékin) et peut varier d’un agrégateur à l’autre en raison des différences d’heure de collecte. L’ordre d’affichage du classement officiel ne correspond pas entièrement au tri par étoiles gagnées.

Vue d’ensemble de la semaine

Le fil conducteur de cette semaine passe des « skills » à la mémoire et à l’infrastructure de collaboration des agents.

  1. La mémoire des agents devient le nouveau goulot d’étranglement — thedotmack/claude-mem, premier du classement général (+9 318 étoiles en une semaine), offre un contexte persistant entre sessions : il compresse ce que l’agent a fait à chaque session puis l’injecte dans les sessions futures. max-sixty/worktrunk (premier du classement Rust) utilise les Git worktrees pour que plusieurs agents travaillent en parallèle sans se marcher dessus, et herdrdev/herdr veut devenir « le runtime où vivent les agents ». Les skills installées, l’étape suivante est de faire en sorte que l’agent se souvienne et collabore bien.
  2. Les agents commencent à prendre en charge toute la chaîne de production — Donchitos/Claude-Code-Game-Studios (2ᵉ du classement général) transforme Claude Code en studio de développement de jeux : 49 agents, 72 skills de workflow, avec une répartition des rôles calquée sur un vrai studio ; calesthio/OpenMontage est un système open source de production vidéo par agents, avec 12 pipelines de production et plus de 700 fichiers de skills. L’agent passe de « écrire du code » à « faire tourner un projet complet ».
  3. Le design anti-goût-IA figure au classement pour la troisième semaine consécutive — Nutlope/hallmark (5ᵉ du classement général), pbakaus/impeccable et Leonxlnx/taste-skill, trois projets de goût en design, dominent le classement en même temps : la « taxe esthétique » du contenu généré par IA devient une infrastructure à part entière.
  4. Le retour des anciens de l’infrastructure — le top 5 du classement Go est presque entièrement composé de piliers du cloud native comme moby, gitea, argo-cd et docker/compose, et le classement Java est lui aussi dominé par keycloak, elasticsearch, cryptomator et StarRocks ; en contraste avec les nouveaux venus agents, cela montre que l’attention de cette semaine reflue vers l’infrastructure de base.
  5. L’IA financière pointe le bout du nez — shiyu-coder/Kronos (6ᵉ du classement Python) est un modèle de langage de base pour les marchés financiers, à surveiller pour celles et ceux qui travaillent sur le trading / les cours.
