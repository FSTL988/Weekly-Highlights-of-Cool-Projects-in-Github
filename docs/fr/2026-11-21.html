Rapport hebdomadaire des projets populaires GitHub — la semaine écoulée

Fenêtre temporelle : du 2026-11-15 au 2026-11-21 (GitHub Trending since=weekly) Heure de vérification : 2026-11-21 08:00 CST (Asia/Shanghai) Note méthodologique : le classement suit l’ordre d’affichage du classement hebdomadaire officiel GitHub Trending ; le nombre d’étoiles gagnées cette semaine est tiré de la page du classement officiel elle-même (« X stars this week »), le total des étoiles provient d’une requête en temps réel à l’API GitHub (autour du 2026-11-21 08:00) et de l’instantané d’un site agrégateur tiers (2026-11-21 04:41, heure de Pékin). L’ordre d’affichage du classement officiel ne correspond pas entièrement au tri par étoiles gagnées.

Vue d’ensemble de la semaine

Le fil conducteur de cette semaine est que l’agent passe de « capable de travailler » à « digne de confiance pour travailler », tandis que les « skills » continuent de se diffuser vers des cas d’usage verticaux.

  1. L’humain dans la boucle (human-in-the-loop) en tête — backnotprop/plannotator, premier du classement général, est un espace de travail qui « permet à l’humain de garder le contrôle dans la boucle de l’agent » ; andrewyng/openworker, 5ᵉ du classement Python (équipe d’Andrew Ng), fait de « l’approbation, de l’audit et du sandbox » l’architecture par défaut d’un agent de bureau ; Tencent/LoopForge ajoute aussi une étape d’approbation humaine dans son processus de livraison. Plus l’agent est capable, plus l’humain doit pouvoir le surveiller.
  2. Les « skills » poursuivent leur verticalisation — la semaine dernière, c’étaient encore des paquets de skills généralistes ; cette semaine, elles se sont différenciées par métier : mvanhorn/last30days-skill (une skill de recherche sur Reddit/X/YouTube/HN), tradermonty/claude-trading-skills (une skill de trading pour les investisseurs particuliers), kajisho5/ffmpeg-skill (une skill de montage vidéo local), coreyhaines31/marketingskills (une skill marketing). Les skills passent du statut de « plugin de l’agent » à celui de « workflow d’un métier ».
  3. Les agents de revue de code entrent dans la pratique des grandes entreprises — alibaba/open-code-review (4ᵉ du classement général, 54 766 étoiles au total) mise sur « un pipeline déterministe validé à l’échelle d’Alibaba + un agent LLM » ; GoogleChrome/modern-web-guidance-src (3ᵉ du classement général) vise à faire suivre aux agents de codage les dernières bonnes pratiques du Web. La revue et les normes deviennent la prochaine étape de l’adoption des agents.
  4. La couche de protocole entre agents et frontend apparaît — ag-ui-protocol/ag-ui (Agent-User Interaction Protocol) et a2ui-project/a2ui (un framework d’UI générative) figurent au classement la même semaine : l’agent ne se contente plus de produire du texte, il doit « faire pousser » des composants directement dans l’interface de l’application.
  5. Les projets d’équipes chinoises émergent en nombre — Alibaba, Tencent, dream-num/univer, jeecgboot/JeecgBoot et DeanChensj/jiangshan-map (une carte interactive de l’histoire de la Chine) figurent au classement la même semaine, couvrant la revue de code, la livraison d’agents, les suites bureautiques, le low-code et le contenu culturel.
  6. Les anciens continuent de se faire remarquer aux marges du classement — jquery revient à la 4ᵉ place du classement JS, openjdk/jdk et SeleniumHQ/selenium mènent le classement Java ; affaan-m/ECC gagne encore 5 598 étoiles cette semaine, pour un total de 307 847 étoiles. Dans la vague des agents, la base d’étoiles des infrastructures établies reste très solide.

4 projets à essayer pour Xtop

En lien avec les directions que vous avez déjà mises en favori (outils IA/Agent, modèles locaux, MCP) et les projets sur lesquels vous travaillez :

  1. tradermonty/claude-trading-skills — Un paquet de skills de trading : analyse de marché, graphiques techniques, calendrier économique, sélection d’actions et développement de stratégies, dans le même workflow que votre plateforme de trading et votre rapport crypto du soir ; vous pouvez comparer directement la structure de ses skills pour organiser votre propre processus d’analyse des cours
  2. andrewyng/openworker — L’agent de bureau de l’équipe d’Andrew Ng, avec l’architecture par défaut « approbation, audit, sandbox » ; si votre plateforme de trading doit ajouter des alertes automatisées ou une exécution automatique, sa conception de contrôle à quatre niveaux (ligne rouge stricte, autorisation graduée, piste d’audit, sandbox) est le modèle le plus intéressant à copier
  3. backnotprop/plannotator — Le premier du classement général cette semaine, un espace de travail pour « l’humain dans la boucle de l’agent » ; quand vous utilisez un agent pour écrire le code de votre plateforme de trading, l’utiliser comme centre pour relire le code, annoter et envoyer des retours économise plus de contexte que de coller du code dans la fenêtre de chat
  4. alibaba/open-code-review — Une revue de code combinant pipeline déterministe et agent LLM, avec des ensembles de règles intégrés pour les NPE, la sécurité des threads, les XSS, les injections SQL, entre autres ; faites-le tourner sur le backend de votre plateforme de trading pour voir quels problèmes il détecte
