This Week at a Glance

This week’s main thread is agents moving from “able to do the work” to “safe to trust with the work”, while “skills” keep spreading into vertical use cases.

  1. Human-in-the-loop tops the chart — backnotprop/plannotator, #1 overall, is a workspace for “keeping humans in control of the agent loop”; andrewyng/openworker (#5 on the Python chart, from Andrew Ng’s team) makes “approvals, audit trails, and sandboxing” the default architecture of a desktop agent; Tencent/LoopForge also adds human approval gates to its delivery flow. The more capable agents get, the more humans need to keep them in sight.
  2. “Skills” keep going vertical — Last week was still general-purpose skill packs; this week they have split into specific trades: mvanhorn/last30days-skill (a research skill spanning Reddit/X/YouTube/HN), tradermonty/claude-trading-skills (a trading skill for retail investors), kajisho5/ffmpeg-skill (a local video editing skill), and coreyhaines31/marketingskills (a marketing skill). Skills are shifting from “an agent’s plugins” to “a profession’s workflow”.
  3. Code-review agents enter big-tech production territory — Alibaba’s alibaba/open-code-review (#4 overall, 54,766 total stars) leads with a “deterministic pipeline + LLM agent, proven at Alibaba’s scale”; GoogleChrome/modern-web-guidance-src (#3 overall) keeps coding agents up to date with the latest web best practices. Review and standards have become the next gate for agents landing in production.
  4. A protocol layer between agents and frontends appears — ag-ui-protocol/ag-ui (the Agent-User Interaction Protocol) and a2ui-project/a2ui (a generative UI framework) trend in the same week: agents no longer output only text, they “grow” components directly into app interfaces.
  5. Chinese teams’ projects cluster at the top — Alibaba, Tencent, dream-num/univer, jeecgboot/JeecgBoot, and DeanChensj/jiangshan-map (an interactive map of Chinese history) trend in the same week, spanning code review, agent delivery, office suites, low-code, and cultural content.
  6. Veterans keep showing up at the edges — jquery returns to the JS chart at #4, openjdk/jdk and SeleniumHQ/selenium lead the Java chart; affaan-m/ECC gains another 5,598 stars this week, reaching 307,847 total. Amid the agent wave, veteran infrastructure projects’ star counts remain solid.
