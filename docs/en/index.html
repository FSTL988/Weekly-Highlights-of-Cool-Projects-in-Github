Latest issue: 2026-11-21 (2026-11-15 to 2026-11-21)

  • Full weekly report: reports/2026-11/github-weekly-2026-11-21.md

This week’s main thread: agents are moving from “able to do the work” to “safe to trust with the work”, while “skills” keep spreading into vertical use cases. 1. Human-in-the-loop takes the top spot — backnotprop/plannotator ranks #1 overall; Andrew Ng’s team’s andrewyng/openworker makes approvals, auditing, and sandboxing the default architecture; Tencent/LoopForge also adds human approval gates to its delivery flow. 2. “Skills” keep going vertical — last30days-skill (research), claude-trading-skills (trading), ffmpeg-skill (video editing), and marketingskills (marketing) all trended in the same week. 3. Code-review agents enter big-tech production territory — Alibaba’s alibaba/open-code-review (#4 overall) and GoogleChrome/modern-web-guidance-src (#3 overall) trended in the same week. 4. Chinese teams’ projects cluster at the top — Alibaba, Tencent, dream-num/univer, jeecgboot/JeecgBoot, and jiangshan-map all trended in the same week; the Java chart was quiet overall.
