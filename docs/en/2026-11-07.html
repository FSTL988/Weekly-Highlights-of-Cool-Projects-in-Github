Time window: 2026-11-01 to 2026-11-07 (GitHub Trending since=weekly) Verified at: 2026-11-07 08:00 CST (Asia/Shanghai) Methodology: Rankings follow GitHub’s official Trending weekly chart display order; weekly stars gained cite a third-party aggregator snapshot (2026-11-07 03:38 Beijing time), and figures may differ across aggregators due to different crawl times. This Week at a Glance

This week’s main thread shifts from “skills” to agent memory and collaboration infrastructure.

  1. Agent memory becomes the new bottleneck — thedotmack/claude-mem, #1 overall (+9,318 stars in a week), provides cross-session persistent context: it compresses what an agent does in each session and injects it into future sessions. max-sixty/worktrunk (#1 on the Rust chart) uses Git worktrees so multiple agents can work in parallel without colliding, and herdrdev/herdr aims to be “the runtime agents live in”. With skills installed, the next step is making agents remember and cooperate.
  2. Agents start taking over entire production lines — Donchitos/Claude-Code-Game-Studios (#2 overall) turns Claude Code into a game development studio: 49 agents and 72 workflow skills, divided by real studio hierarchy; calesthio/OpenMontage is an open-source agentic video production system with 12 production pipelines and 700+ skill files. Agents move from “writing code” to “running whole projects”.
  3. Anti-AI-look design trends for a third straight week — Nutlope/hallmark (#5 overall), pbakaus/impeccable, and Leonxlnx/taste-skill, three design-taste projects, dominate the charts together; the “aesthetics tax” on AI-generated content is becoming formal infrastructure.
  4. Infrastructure veterans return — The Go top five is almost entirely established cloud-native projects — moby, gitea, argo-cd, docker/compose, and more — and the Java chart is likewise led by keycloak, elasticsearch, cryptomator, and StarRocks; against the new agentic arrivals, this shows attention flowing back toward underlying infrastructure.
  5. Financial AI emerges — shiyu-coder/Kronos (#6 on the Python chart) is a language foundation model for financial markets, worth a look for anyone working on trading / market-related projects.
