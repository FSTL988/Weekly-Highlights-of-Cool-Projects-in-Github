This Week at a Glance

This week’s keyword is still agent skills, but the wind has shifted from “building more skills” to “managing skills well” and “giving agents better taste”.

  1. Skill security and quality become the new focus — cloudflare/security-audit-skill, #1 overall (+14,320 stars in a week), lets agents run multi-stage security audits themselves; NVIDIA’s SkillSpector scans skills for prompt injection, malicious code, and data exfiltration. The more skills you install, the more someone needs to check the skills themselves.
  2. Big tech ships skills directly — Anthropic launches knowledge-work-plugins for knowledge workers, AWS launches the official agent-toolkit-for-aws, and Anthropic’s skills repository keeps trending; skill distribution moves from community-driven to an official default.
  3. Agents start minding “taste” and “aesthetics” — pbakaus/impeccable (+9,713 stars in a week) gives agents a design vocabulary, while taste-skill and jakubkrehel/skills teach agents to design interfaces and do art direction; whether AI-written pages look good is now taken seriously.
  4. Finance agents heat up again — TauricResearch/TradingAgents (+5,557 stars in a week) returns to the overall top five, and multi-agent trading frameworks draw attention again; the Rust chart also features crossover projects such as WiFi signal sensing and a robot duck.
