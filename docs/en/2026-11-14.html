Time window: 2026-11-08 to 2026-11-14 (GitHub Trending since=weekly) Verified at: 2026-11-14 08:00 CST (Asia/Shanghai) Methodology: Rankings follow GitHub’s official Trending weekly chart display order; weekly stars gained cite a third-party aggregator snapshot (2026-11-14 03:57 Beijing time), and figures may differ across aggregators due to different crawl times. This Week at a Glance

This week’s main thread is agent tools moving from “skill packs” to “runtime environments”, while veteran tools unexpectedly revive.

  1. “Skills” are still the mainstream distribution format, but splitting apart — anthropics/skills holds in the overall top ranks for a fourth straight week, while mattpocock/skills, addyosmani/agent-skills, and google/skills trend in the same week; “skills” have become the default packaging format for agent capabilities, and the competition shifts from “having skills” to “skill quality and security”.
  2. Agents’ hands and eyes reach the desktop and browser — vercel-labs/agent-browser (#1 on the Rust chart, #4 overall) and agent-desktop trend in the same week, giving agents browser automation and computer-operation abilities; milind-soni/OpenMausBot (#3 overall) is an open-source Grok Bot alternative with its own VM for the bot.
  3. Old projects revive — #1 overall is sherlock-project/sherlock, a veteran OSINT tool from 2018 (find social accounts across the web by username), with total stars past 110,000; google-deepmind/mujoco (a physics simulator) also returns to the overall top ten. Classic tools are being rediscovered on the agent wave.
  4. Agent security becomes a new track — openai/codex-security (#3 on the TypeScript chart) and NVIDIA/SkillSpector (scans agent skills for prompt injection and supply-chain risk) trend in the same week; cloudflare/security-audit-skill gains another 10,700 stars this week, topping the JS chart for a fourth straight week. The more skills you install, the more someone needs to verify them.
  5. Financial AI keeps emerging — ZhuLinsen/daily_stock_analysis (LLM-powered multi-market stock analysis with zero-cost scheduled runs) climbs to #6 overall and #4 on the Python chart; NVIDIA/auto-ontology (a semantic graph reasoning layer for data) is #5 on the Python chart.
  6. Infrastructure veterans keep flowing back — prometheus tops the Go chart, with cli/cli, etcd, and trivy trending in the same week; the Java chart features familiar faces such as TheAlgorithms/Java, elasticsearch, NewPipe, and floci. Agent newcomers and underlying infrastructure each hold half the chart.
