每周 GitHub 热门项目精选。来源是 GitHub Trending 官方周榜（since=weekly）及各语言子榜，按领域整理成清单；每周六早上 8 点更新一期，完整周报见 reports/<年月>/。

说明：这里是项目清单版 — 项目以链接形式收录，不把上游仓库的代码本体复制进来。点击项目名即可跳转到原仓库。

最新一期：2026-11-21（2026-11-15 至 2026-11-21）

  • 完整周报：reports/2026-11/github-weekly-2026-11-21.md

本周主线：Agent 从“能干活”走向“让人放心地干活”，同时“技能”继续向垂直场景扩散。 1. 人在回路登顶 — backnotprop/plannotator 全站第一；吴恩达团队的 andrewyng/openworker 把审批、审计、沙箱做成默认架构；Tencent/LoopForge 也在交付流程里加了人工审批关卡。 2. “技能”继续垂直化 — last30days-skill（调研）、claude-trading-skills（交易）、ffmpeg-skill（视频剪辑）、marketingskills（营销）同周上榜。 3. 代码评审 Agent 进入大厂实战口径 — 阿里 alibaba/open-code-review（全站第四）、GoogleChrome/modern-web-guidance-src（全站第三）同周上榜。 4. 中国团队项目集中冒头 — 阿里、腾讯、dream-num/univer、jeecgboot/JeecgBoot、jiangshan-map 同周在榜；Java 榜整体偏冷。
