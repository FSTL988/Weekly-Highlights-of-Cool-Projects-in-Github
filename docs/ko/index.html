이번 주 핵심 흐름: Agent가 “일을 할 수 있는” 단계에서 “안심하고 일을 맡길 수 있는” 단계로 나아가고, 동시에 “스킬”은 계속해서 수직 분야로 확산되고 있습니다. 1. 휴먼 인 더 루프가 정상에 오름 — backnotprop/plannotator가 전체 1위. 앤드류 응(Andrew Ng) 팀의 andrewyng/openworker는 승인, 감사, 샌드박스를 기본 아키텍처로 삼았고, Tencent/LoopForge도 딜리버리 과정에 인간 승인 단계를 추가했습니다. 2. “스킬”의 계속되는 수직화 — last30days-skill(조사), claude-trading-skills(거래), ffmpeg-skill(영상 편집), marketingskills(마케팅)가 같은 주에 순위에 올랐습니다. 3. 코드 리뷰 Agent가 대기업 실전 수준에 진입 — 알리바바 alibaba/open-code-review(전체 4위), GoogleChrome/modern-web-guidance-src(전체 3위)가 같은 주에 순위에 올랐습니다. 4. 중국 팀 프로젝트가 집중적으로 부상 — 알리바바, 텐센트, dream-num/univer, jeecgboot/JeecgBoot, jiangshan-map이 같은 주에 순위에 올랐고, Java 순위는 전반적으로 조용했습니다.
