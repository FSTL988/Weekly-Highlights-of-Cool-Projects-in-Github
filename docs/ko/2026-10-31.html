이번 주 개요

이번 주의 키워드는 여전히 Agent 스킬(skills) 이지만, 흐름은 “스킬을 더 많이 만드는 것”에서 “스킬을 잘 관리하고 Agent에게 더 좋은 취향을 갖게 하는 것”으로 바뀌었습니다.

  1. 스킬 안전과 품질이 새로운 초점 — 전체 1위 cloudflare/security-audit-skill(한 주 +14,320 스타)은 Agent 스스로 다단계 보안 감사를 하게 합니다. NVIDIA의 SkillSpector는 스킬 안의 프롬프트 인젝션, 악성 코드, 데이터 유출을 전문적으로 스캔합니다. 스킬을 많이 설치할수록 스킬 자체를 검사해 줄 누군가가 더 필요합니다.
  2. 대기업이 직접 스킬을 내놓기 시작 — Anthropic이 지식 근로자를 위한 knowledge-work-plugins를 출시했고, AWS가 공식 agent-toolkit-for-aws를 출시했으며, Anthropic의 skills 저장소도 계속 순위에 오르고 있습니다. 스킬 배포가 커뮤니티 자발적 움직임에서 공식 기본 사양으로 바뀌고 있습니다.
  3. Agent가 “취향”과 “미감”을 말하기 시작 — pbakaus/impeccable(한 주 +9,713 스타)은 Agent에게 디자인 어휘를 주고, taste-skill과 jakubkrehel/skills는 Agent에게 인터페이스를 만들고 아트 디렉션을 하도록 가르칩니다. AI가 쓴 페이지가 볼 만한지, 이제 진지하게 관리하는 사람이 생겼습니다.
  4. 금융 Agent 열기가 다시 상승 — TauricResearch/TradingAgents(한 주 +5,557 스타)가 전체 상위 5위권으로 돌아오면서 다중 Agent 트레이딩 프레임워크가 다시 주목받고 있습니다. 동시에 Rust 순위에는 WiFi 신호 감지, 로봇 오리 등 경계를 넘나드는 프로젝트가 등장했습니다.
