기간: 2026-11-15 ~ 2026-11-21 (GitHub Trending since=weekly) 확인 시간: 2026-11-21 08:00 CST (Asia/Shanghai) 집계 기준: 순위는 GitHub 공식 Trending 주간 순위의 표시 순서를 기준으로 합니다. 이번 주 증가 스타 수는 공식 순위 페이지 자체(“X stars this week”)에서 가져왔고, 전체 스타 수는 GitHub API 실시간 조회(2026-11-21 08:00 전후)와 제3자 집계 사이트 스냅샷(2026-11-21 04:41 베이징 시간)에서 가져왔습니다. 공식 순위의 표시 순서는 증가 스타 수 순서와 완전히 일치하지 않습니다.

이번 주 개요

이번 주의 핵심 흐름은 Agent가 “일을 할 수 있는” 단계에서 “안심하고 일을 맡길 수 있는” 단계로 나아가고, 동시에 “스킬”이 계속 수직 분야로 확산되는 것 입니다.

  1. 휴먼 인 더 루프(human-in-the-loop)가 정상에 오름 — 전체 1위 backnotprop/plannotator는 “Agent 루프 안에서 사람이 주도권을 유지하게 하는” 워크스페이스입니다. Python 순위 5위 andrewyng/openworker(앤드류 응 팀)는 “승인, 감사, 샌드박스”를 데스크톱 Agent의 기본 아키텍처로 삼았습니다. Tencent/LoopForge도 딜리버리 과정에 인간 승인 단계를 추가했습니다. Agent가 일을 잘할수록 사람은 더 잘 지켜봐야 합니다.
  2. “스킬”의 계속되는 수직화 — 지난주까지만 해도 범용 스킬 팩이었는데, 이번 주에는 이미 구체적인 직종으로 갈라졌습니다. mvanhorn/last30days-skill(Reddit/X/YouTube/HN을 넘나드는 조사 스킬), tradermonty/claude-trading-skills(개인 투자자를 위한 트레이딩 스킬), kajisho5/ffmpeg-skill(로컬 영상 편집 스킬), coreyhaines31/marketingskills(마케팅 스킬)입니다. 스킬은 “Agent의 플러그인”에서 “어떤 직업의 워크플로”로 바뀌고 있습니다.
  3. 코드 리뷰 Agent가 대기업 실전 수준에 진입 — 알리바바 alibaba/open-code-review(전체 4위, 전체 스타 54,766)는 “알리바바 규모로 검증된 결정적 파이프라인 + LLM Agent”를 내세웁니다. GoogleChrome/modern-web-guidance-src(전체 3위)는 코딩 Agent가 최신 웹 모범 사례를 따라가게 합니다. 리뷰와 규범이 Agent 정착의 다음 관문이 되었습니다.
  4. Agent와 프론트엔드의 프로토콜 계층 등장 — ag-ui-protocol/ag-ui(Agent-User Interaction Protocol), a2ui-project/a2ui(생성형 UI 프레임워크)가 같은 주에 순위에 올랐습니다. Agent는 더 이상 텍스트만 출력하지 않고, 앱 인터페이스 안에 직접 컴포넌트를 “자라게” 합니다.
  5. 중국 팀 프로젝트의 집중 등장 — 알리바바, 텐센트, dream-num/univer, jeecgboot/JeecgBoot, DeanChensj/jiangshan-map(중국 역사 인터랙티브 지도)이 같은 주에 순위에 올라 코드 리뷰, Agent 딜리버리, 오피스 스위트, 로우코드, 문화 콘텐츠를 아울렀습니다.
  6. 베테랑이 순위 가장자리에서 계속 존재감 과시 — jquery가 JS 순위 4위로 돌아왔고, openjdk/jdk, SeleniumHQ/selenium이 Java 순위를 이끌었습니다. affaan-m/ECC는 이번 주에 다시 5,598 스타가 늘어 전체 스타가 이미 307,847에 달했습니다. Agent 열풍 속에서도 베테랑 인프라의 스타 수 기반은 여전히 탄탄합니다.
