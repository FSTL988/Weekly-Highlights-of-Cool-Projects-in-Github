이번 주 개요

이번 주의 핵심 흐름은 Agent 도구가 “스킬 팩”에서 “실행 환경”으로 나아가고, 동시에 베테랑 도구가 뜻밖의 부활을 맞은 것 입니다.

  1. “스킬”은 여전히 배포의 주류이지만 분화가 시작됨 — anthropics/skills가 4주 연속 전체 상위권에 굳건히 자리했고, mattpocock/skills, addyosmani/agent-skills, google/skills가 같은 주에 순위에 올랐습니다. “스킬”은 이미 Agent 능력의 기본 포장 형식이 되었고, 경쟁 포인트는 “스킬이 있느냐”에서 “스킬의 품질과 안전”으로 바뀌었습니다.
  2. Agent의 손과 눈이 데스크톱과 브라우저에 닿음 — vercel-labs/agent-browser(Rust 순위 1위, 전체 4위)와 agent-desktop이 같은 주에 순위에 올라 Agent에게 브라우저 자동화와 컴퓨터 조작 능력을 부여했습니다. milind-soni/OpenMausBot(전체 3위)은 오픈소스 Grok Bot 대안으로, Bot이 쓸 가상 머신을 자체 제공합니다.
  3. 오래된 프로젝트의 부활 — 전체 1위는 2018년의 베테랑 OSINT 도구 sherlock-project/sherlock(사용자 이름으로 전 웹에서 소셜 계정을 찾음)으로, 전체 스타가 이미 11만을 넘었습니다. google-deepmind/mujoco(물리 시뮬레이터)도 전체 상위 10위권으로 돌아왔습니다. 고전 도구가 Agent 열풍을 타고 다시 발견되고 있습니다.
  4. Agent 보안이 새로운 경주 트랙 — openai/codex-security(TypeScript 순위 3위), NVIDIA/SkillSpector(Agent 스킬 안의 프롬프트 인젝션과 공급망 위험을 스캔)가 같은 주에 순위에 올랐습니다. cloudflare/security-audit-skill은 이번 주에 다시 10,700 스타가 늘어 JS 순위 4주 연속 1위를 지켰습니다. 스킬을 많이 설치할수록 누군가 검수해야 합니다.
  5. 금융 AI가 계속 등장 — ZhuLinsen/daily_stock_analysis(LLM 기반 다중 시장 주식 분석, 무비용 정기 실행)가 전체 6위, Python 순위 4위로 뛰어올랐습니다. NVIDIA/auto-ontology(데이터에 의미 그래프 추론 레이어를 구축)는 Python 순위 5위입니다.
  6. 인프라 베테랑의 계속되는 회귀 — Go 순위 1위는 prometheus이고, cli/cli, etcd, trivy가 같은 주에 순위에 올랐습니다. Java 순위는 TheAlgorithms/Java, elasticsearch, NewPipe, floci 등 익숙한 얼굴들입니다. Agent 신흥 강자와 하위 인프라가 반반씩 순위를 나눠 갖고 있습니다.
