今週の概要

今週の主軸は Agent ツールが「スキルパック」から「実行環境」へ向かう一方で、老舗ツールが予想外に復活したこと です。

  1. 「スキル」は依然として配布の主流だが、分化が始まる — anthropics/skills が 4 週連続で全サイト上位を維持し、mattpocock/skills、addyosmani/agent-skills、google/skills が同週にランクイン。「スキル」はすでに Agent 能力のデフォルトの包装形式となり、競争のポイントは「スキルがあるかどうか」から「スキルの品質と安全性」へ移っています。
  2. Agent の手と目がデスクトップとブラウザに届く — vercel-labs/agent-browser（Rust ランキング 1 位、全サイト 4 位）と agent-desktop が同週にランクインし、Agent にブラウザ自動化とコンピューター操作の能力を与えます。milind-soni/OpenMausBot（全サイト 3 位）はオープンソースの Grok Bot 代替品で、Bot 用の仮想マシンを内蔵しています。
  3. 老舗プロジェクトの復活 — 全サイト 1 位は 2018 年の老舗 OSINT ツール sherlock-project/sherlock（ユーザー名で全網のソーシャルアカウントを探す）で、総スター数はすでに 11 万を突破。google-deepmind/mujoco（物理シミュレーター）も全サイト上位 10 位に返り咲きました。古典的なツールが Agent の波に乗って再発見されています。
  4. Agent セキュリティが新たな競争分野に — openai/codex-security（TypeScript ランキング 3 位）、NVIDIA/SkillSpector（Agent スキル内のプロンプトインジェクションとサプライチェーンリスクをスキャン）が同週にランクイン。cloudflare/security-audit-skill は今週さらに 10,700 スター増え、JS ランキングで 4 週連続 1 位です。スキルを多く入れるほど、誰かが検証しなければなりません。
  5. 金融 AI が引き続き台頭 — ZhuLinsen/daily_stock_analysis（LLM 駆動のマルチマーケット株式分析、ゼロコスト定期実行）が全サイト 6 位、Python ランキング 4 位に躍進。NVIDIA/auto-ontology（データにセマンティックグラフ推論層を構築）は Python ランキング 5 位です。
  6. インフラのベテランが引き続き回帰 — Go ランキング 1 位は prometheus で、cli/cli、etcd、trivy が同週にランクイン。Java ランキングは TheAlgorithms/Java、elasticsearch、NewPipe、floci といったおなじみの顔ぶれです。Agent の新興勢力と基盤インフラが半分ずつを占めています。
