今週の概要

今週の主軸は Agent が「仕事ができる」から「安心して任せられる」へ進む一方で、「スキル」が垂直分野へ拡散を続けたこと です。

  1. 人間参加型（human-in-the-loop）が首位に — 全サイト 1 位の backnotprop/plannotator は「Agent のループの中で人が主導権を握り続けられる」ワークスペースです。Python ランキング 5 位の andrewyng/openworker（アンドリュー・ン氏のチーム）は「承認、監査、サンドボックス」をデスクトップ Agent のデフォルトアーキテクチャに組み込み、Tencent/LoopForge もデリバリーフローに人間の承認ステップを追加しました。Agent が有能になるほど、人が見張る必要があります。
  2. 「スキル」の垂直化が続く — 先週はまだ汎用スキルパックでしたが、今週はすでに具体的な職種へ分化しています。mvanhorn/last30days-skill（Reddit／X／YouTube／HN 横断の調査スキル）、tradermonty/claude-trading-skills（個人投資家向け取引スキル）、kajisho5/ffmpeg-skill（ローカル動画編集スキル）、coreyhaines31/marketingskills（マーケティングスキル）です。スキルは「Agent のプラグイン」から「ある職業のワークフロー」へ変わりつつあります。
  3. コードレビュー Agent が大手の実戦レベルへ — アリババの alibaba/open-code-review（全サイト 4 位、総スター数 54,766）は「アリババ規模で検証された決定論的パイプライン + LLM Agent」を掲げ、GoogleChrome/modern-web-guidance-src（全サイト 3 位）はコーディング Agent を最新の Web ベストプラクティスに追いつかせるものです。レビューと規範が、Agent を現場に落とし込む次の関門になっています。
  4. Agent とフロントエンドのプロトコル層が登場 — ag-ui-protocol/ag-ui（Agent-User Interaction Protocol）と a2ui-project/a2ui（生成 UI フレームワーク）が同週にランクイン。Agent はもうテキストだけを出力するのではなく、アプリの UI に直接コンポーネントを「生やす」ようになります。

  6. ベテランがランキングの周辺で存在感を示し続ける — jquery が JS ランキング 4 位に返り咲き、openjdk/jdk と SeleniumHQ/selenium が Java ランキングをリード。affaan-m/ECC は今週さらに 5,598 スター増え、総スター数はすでに 307,847 に達しました。Agent の波の中でも、老舗インフラのスター数の土台は依然として堅いです。
