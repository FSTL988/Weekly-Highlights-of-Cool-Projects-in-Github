毎週の GitHub 人気プロジェクト厳選。出典は GitHub Trending 公式週間ランキング（since=weekly）および各言語別サブランキングで、分野別に整理したリストです。毎週土曜朝 8 時に 1 期更新し、完全版の週報は reports/<年月>/ にあります。

最新号：2026-11-21（2026-11-15 〜 2026-11-21）

  • 完全版週報：reports/2026-11/github-weekly-2026-11-21.md

今週の主軸：Agent は「仕事ができる」から「安心して任せられる」へ。同時に「スキル」は垂直分野へ拡散を続けています。 1. 人間参加型（ヒューマン・イン・ザ・ループ）が首位に — backnotprop/plannotator が全サイト 1 位。アンドリュー・ン氏のチームによる andrewyng/openworker は承認・監査・サンドボックスをデフォルトのアーキテクチャに組み込み、Tencent/LoopForge もデリバリーフローに人間の承認ステップを追加。 2. 「スキル」の垂直化が続く — last30days-skill（調査）、claude-trading-skills（取引）、ffmpeg-skill（動画編集）、marketingskills（マーケティング）が同週にランクイン。 3. コードレビュー Agent が大手の実戦レベルへ — アリババの alibaba/open-code-review（全サイト 4 位）、GoogleChrome/modern-web-guidance-src（全サイト 3 位）が同週にランクイン。 4. 中国チームのプロジェクトが集中して台頭 — アリババ、テンセント、dream-num/univer、jeecgboot/JeecgBoot、jiangshan-map が同週にランクイン。Java ランキング全体はやや低調。
