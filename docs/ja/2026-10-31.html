今週の概要

今週のキーワードは引き続き Agent スキル（skills） ですが、風向きは「スキルをもっと作る」から「スキルをきちんと管理する」「Agent に品位を持たせる」へと変わりました。

  1. スキルの安全性と品質が新たな焦点に — 全サイト 1 位の cloudflare/security-audit-skill（1 週間で +14,320 スター）は Agent 自身に多段階セキュリティ監査をさせます。NVIDIA の SkillSpector はスキル内のプロンプトインジェクション、悪意のあるコード、データ流出を専門にスキャンします。スキルを多く入れるほど、スキル自体を検査する仕組みが必要になります。
  2. 大手企業が自らスキルを出すように — Anthropic は知識労働者向けに knowledge-work-plugins を公開し、AWS は公式の agent-toolkit-for-aws を発表。Anthropic の skills リポジトリも引き続きランクインしており、スキルの配布はコミュニティ主導から公式の標準装備へと変わりつつあります。
  3. Agent が「品位」と「美意識」を語り始める — pbakaus/impeccable（1 週間で +9,713 スター）は Agent にデザインの語彙を与え、taste-skill と jakubkrehel/skills は Agent にインターフェース制作やアートディレクションを教えます。AI が書いたページが見られるものかどうか、真剣に管理する人が出てきました。
  4. 金融 Agent の熱が再燃 — TauricResearch/TradingAgents（1 週間で +5,557 スター）が全サイト上位 5 位に返り咲き、マルチエージェント取引フレームワークが再び注目を集めています。一方、Rust ランキングには WiFi 信号センシングやロボットアヒルといった異分野のプロジェクトも登場しました。
